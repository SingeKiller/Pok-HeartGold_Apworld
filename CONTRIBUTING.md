# Contributing

This project builds an [Archipelago](https://archipelago.gg) world for
Pokémon HeartGold (US).

## Getting started

1. Clone the repository.
2. Install dev dependencies: `pip install -r requirements-dev.txt`.
3. Run `python data_gen.py` after cloning and after any change under
   `data_gen/` or `data_gen_templates/`.
4. Run tests with `pytest` and lint with `ruff check .` before opening a PR.

## Pull requests

- One coherent change per PR; describe the *why*, not just the *what*.
- Keep generated data (`data/`) out of commits — it is derived from
  `data_gen/` and regenerated by `python data_gen.py`.
- The `ressources/` directory (decomp and reference world, both external
  projects) is git-ignored and must never be committed.
